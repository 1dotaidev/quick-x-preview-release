# Quick X Preview — Releases

Downloads and the Sparkle update feed for **Quick X Preview**, a macOS Quick Look
extension that previews folder contents and archives without unzipping them.

- **Download the latest version:** see [Releases](https://github.com/1dotaidev/quick-x-preview-release/releases/latest)
- **Update feed:** `https://raw.githubusercontent.com/1dotaidev/quick-x-preview-release/main/appcast.xml`

## Requirements

macOS 13.0 or later.

## Installing

1. Open the downloaded `.dmg` and drag **Quick X Preview** into Applications.
2. Launch it once and follow the setup guide to enable the two Quick Look extensions.
3. Select a folder or archive in Finder and press **Space**.

## Updates

The app checks this feed automatically and can also be updated from
**Quick X Preview → Check for Updates…**.
